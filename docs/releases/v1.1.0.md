# Smart Download Renamer v1.1.0

Smart Download Renamer v1.1.0 introduces local data backup and restore, expanded website recognition across over 100 common services and country domains, and four new interface languages.

## Highlights

- **Local backup and restore**: Export or import settings, custom domain rules, and download history as a private JSON file with automatic structure validation.
- **Expanded website detection**: Built-in catalog recognizing 100+ services (cloud drives, learning platforms, travel, developer tools, banking, shopping) with automatic human-friendly naming for unlisted domains and country TLDs (`.co.uk`, `.com.tr`, etc.).
- **Download host fallback**: Resolves meaningful source names when downloads are routed through generic CDNs or cloud storage hosts.
- **Four new languages**: Full localization support added for Spanish (`es`), German (`de`), French (`fr`), and Brazilian Portuguese (`pt-BR`), joining existing English and Turkish.
- **Language selector & auto-detection**: Detects supported browser language on first launch and provides an instant in-app language picker in Settings.
- **Safe import guards**: Imported historical records are sanitized to prevent opening stale local files via expired Chrome download IDs.

## Privacy and permissions

The extension remains strictly local-first:
- No telemetry, no external network requests, no remote tracking, and no user accounts.
- Permissions remain identical: `downloads`, `downloads.open`, and `storage`.
