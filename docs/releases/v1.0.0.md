# Smart Download Renamer v1.0.0

The first public release of Smart Download Renamer turns unclear Chrome downloads into clean, searchable filenames while keeping processing and history on the user's device.

## Highlights

- Automatically suggests descriptive filenames as downloads begin.
- Shows the final filename, original filename, saved location, source, size, and file type.
- Opens completed files or reveals them in their folder only after a user action.
- Provides filename templates, conflict handling, executable protection, and website-specific rules.
- Includes searchable local rename history and clear data controls.
- Supports English and Turkish interfaces with light and dark themes.
- Includes a responsive options experience and compact Chrome popup.

## Privacy and permissions

The extension has no account, analytics, advertising, backend, or cloud synchronization. It does not read downloaded file contents or transmit download metadata.

Permissions are limited to:

- `downloads` for detecting downloads, suggesting names, and revealing files.
- `downloads.open` for the user-requested Open file action.
- `storage` for local settings, rules, language, theme, and rename history.

Read the [privacy policy](../privacy-policy.md) and [permission justifications](../chrome-web-store/permission-justifications.md).
