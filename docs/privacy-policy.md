# Privacy Policy for Smart Download Renamer

Last updated: July 19, 2026

Smart Download Renamer is a local-first Chrome extension that suggests clearer names for downloaded files and helps users find completed downloads. This policy explains the data the extension handles and how it is used.

## Data handled by the extension

To provide its single purpose, the extension can handle:

- Download metadata supplied by Chrome, including the original filename, download URL, final URL, referrer, source domain, MIME type, file extension, timestamps, completion state, file size, and local save path.
- Suggested and final filenames, rename status, and skip or error reasons.
- User settings, filename templates, website rules, interface language, theme, and rename history.

The extension does not read or inspect the contents of downloaded files.

## How data is used and stored

Download metadata is used only to classify a download, detect its source, suggest a filename, show where the completed file was saved, and let the user open the file or reveal it in its folder.

All processing happens on the user's device. Settings, rules, and rename history are stored in `chrome.storage.local`. Smart Download Renamer has no developer-operated server, analytics service, advertising SDK, account system, or cloud synchronization.

## Data sharing

Smart Download Renamer does not transmit, sell, rent, or share download metadata or extension data with the developer or any third party. The developer cannot access data stored by the extension.

The interface contains a voluntary Patreon link. Patreon opens only after the user clicks the link. No download metadata or extension data is sent to Patreon.

## User choices and deletion

Users can pause automatic renaming at any time. Rename history can be cleared from the History page. All extension settings, rules, theme, language, and history can be cleared from the About page. Removing the extension also removes its local extension storage according to Chrome's behavior.

## Chrome Web Store Limited Use disclosure

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Data is used only to provide or improve the extension's single purpose. It is not used for personalized advertising, creditworthiness, lending, or unrelated purposes. Humans are not allowed to read extension user data because that data is never transmitted to the developer.

## Changes

Material changes to these practices will be disclosed in the extension interface and this policy before new data handling begins.
