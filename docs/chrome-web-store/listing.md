## Reviewer instructions

No account, username, password, payment, or external service is required.

1. Install the extension and open its toolbar popup.
2. Download a non-sensitive sample PDF or ZIP file.
3. Reopen the popup to review the filename, status, source, type, size, and saved location.
4. Use **Show in folder** to verify the completed download action.
5. Open **Settings** to review templates, website rules, local history, privacy information, and the English/Turkish language selector.

The Patreon link is voluntary and does not unlock features.
