# Chrome Web Store submission pack

Use these files when creating the Chrome Web Store item:

- [Shared listing information](listing.md)
- [English listing](listings/en.md)
- [Turkish listing](listings/tr.md)
- [Privacy practices answers](privacy-practices.md)
- [Permission justifications](permission-justifications.md)
- [Store asset requirements](assets.md)
- [Submission checklist](submission-checklist.md)
- [Privacy policy](../privacy-policy.md)
- [Support information](../support.md)

The public URLs become suitable for the Store dashboard after these files are merged into the public `main` branch.

Run `npm run release:check` before building the final ZIP. Upload and submission in the Chrome Web Store Developer Dashboard remain manual account-holder actions.
