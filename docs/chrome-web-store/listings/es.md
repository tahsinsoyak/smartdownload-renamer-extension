# Spanish Store listing

## Title

`Renombrador Inteligente de Descargas`

## Summary

`Renombra automáticamente tus descargas con nombres claros y fáciles de encontrar.`

## Detailed description

Smart Download Renamer te ayuda a mantener tus descargas organizadas asignando nombres claros y uniformes a los archivos desde el momento en que se descargan.

Cuando comienza una descarga, la extensión aprovecha los metadatos suministrados por el navegador para identificar el sitio web de procedencia y la categoría del archivo, aplicando tu plantilla de nombres elegida. Al completarse, la ventana emergente muestra el nombre final, el nombre original, el sitio web de origen, el tamaño del archivo y la carpeta de guardado. Puedes abrir el archivo completado o localizarlo en tu carpeta con un solo clic.

Características principales:

- Sugerencias automáticas de nombres al comenzar cada descarga
- Detección del sitio de origen mediante la dirección y el dominio de descarga
- Clasificación contextual según las propiedades y cabeceras del archivo
- Plantillas de nombres personalizables con variables de fecha, fuente y documento
- Reglas por dominio para definir nombres de origen personalizados en sitios específicos
- Protección automática para instaladores y programas ejecutables
- Historial local de descargas con opción de búsqueda y exportación
- Copia de seguridad y restauración local de ajustes, reglas e historial
- Acciones rápidas para abrir archivos completados o mostrarlos en la carpeta
- Modos de visualización claro y oscuro
- Interfaz disponible en varios idiomas

Privacidad y seguridad:
Todo el procesamiento se lleva a cabo íntegramente en tu navegador y en tu equipo. Los datos de descarga, nombres de archivo, URL, ajustes e historial nunca se envían a servidores externos ni a terceros. La extensión no requiere cuentas, no lee el contenido interior de tus archivos y está completamente libre de publicidad, análisis o seguimiento.

Smart Download Renamer es completamente gratuita. Se incluye un enlace voluntario a Patreon para quienes deseen apoyar el mantenimiento del proyecto, sin que ello condicione ninguna función.
