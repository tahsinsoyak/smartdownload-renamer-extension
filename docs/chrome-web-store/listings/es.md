# Spanish Store listing

## Title

`Renombrador Inteligente de Descargas`

## Summary

`Renombra automáticamente tus descargas con nombres claros y fáciles de encontrar.`

## Detailed description

Smart Download Renamer te ayuda a identificar al instante qué archivo has descargado, de qué sitio web procede, cuál es su nombre definitivo y en qué carpeta de tu equipo lo ha guardado Chrome.

En cuanto se inicia una descarga, la extensión utiliza los metadatos suministrados por Chrome para detectar la fuente y el tipo de documento, sugiriendo un nombre limpio y descriptivo según tu plantilla preferida. Al finalizar la descarga, la ventana emergente muestra el nombre final, el nombre original, el sitio web de origen, el tipo de archivo, el tamaño y la carpeta de destino. Podrás abrir el archivo completado o mostrarlo en su carpeta con un solo clic.

Características principales:

- Sugerencias automáticas de nombres de archivo para nuevas descargas
- Detección de origen en más de 100 sitios web conocidos y derivación inteligente para dominios con sufijos territoriales (.es, .co.uk, etc.)
- Reconocimiento de sitio web de origen incluso cuando el archivo se descarga desde servidores CDN o almacenamiento en la nube
- Clasificación automática para facturas, recibos, certificados, nóminas, informes, archivos comprimidos, imágenes y más
- Plantillas de nombres personalizables y formatos de fecha flexibles
- Reglas específicas por dominio para personalizar nombres y tipos de documento
- Protección integrada para archivos ejecutables y aplicaciones (.exe, .pkg, .dmg)
- Historial local de descargas con motor de búsqueda y exportación JSON
- Copia de seguridad y restauración local (Backup & Restore) de ajustes, reglas e historial
- Acciones rápidas: Abrir archivo y Mostrar en carpeta
- Temas visuales claro y oscuro
- Interfaz disponible en 6 idiomas: español, inglés, turco, alemán, francés y portugués de Brasil

La privacidad es lo primero:
Todos los metadatos de descarga, nombres de archivo, URL, rutas locales, ajustes, reglas e historial se procesan de forma 100% local en tu navegador Chrome. Nada se envía al desarrollador ni a terceros. La extensión jamás lee el contenido de tus archivos descargados, no requiere registro ni cuentas, y carece de análisis, publicidad, rastreadores o servidores en la nube.

Smart Download Renamer es completamente gratuita. Se incluye un enlace voluntario a Patreon para quienes deseen apoyar su desarrollo continuado; dicho enlace no desbloquea funciones ni es obligatorio.
